# 🇩🇿 خطة التوحيد الشاملة: لوحة التحكم المركزية الموحدة لمدير النظام (Super Admin All-in-One Command Center)
### دمج المنظومة المركزية لمتابعة الـ 58 ولاية مع كاونتر الخدمات واستوديو التوليد الرقمي · سهلة Sahla 2.0

---

## 🎯 1. الرؤية والهدف الاستراتيجي (Strategic Vision)

عند تسجيل دخول مدير النظام الوطني (`admin@sahla.dz`)، ينبغي أن تُفتح أمامه **لوحة تحكم سيادية موحدة وشاملة (Unified Sovereign Command Center)** تمزج بسلاسة بين:
1. **القيادة الوطنية المركزية (National Super Admin Hub):** متابعة الـ 58 ولاية، شبكة الأكشاك والموزعين، الفوترة وعقود B2B، توليد دفعات كروت الشحن، وفريق الإشراف مع البث الوطني العاجل.
2. **كاونتر الخدمات والتشغيل الفوري (Counter & Service Studio):** استوديو توليد الوثائق الرسمية والمستندات (CV، صور بيومترية، بطاقة رمادية، وثائق أكاديمية)، سجل الوثائق والمستندات، رصيد المحفظة، وفحص الطباعة اللاسلكية.

> **النتيجة المطلوبة:** القضاء التام على ازدواجية وتشتت الواجهات بين `/admin` و `/dashboard`؛ بحيث تصبح الواجهة منصة واحدة متكاملة مبنية بمعايير **Shadcn UI**، وتوفر أقصى درجات الراحة البصرية، ودعم كامل للوضعين الليلي والنهاري (Dark/Light Mode)، وموجهة بالكامل للغة العربية (RTL First).

## 🎛️ 4. الهيدر السيادي الموحد (Unified Command Header & Quick Actions)

يحتوي الهيدر العلوي لمدير النظام على كل الأدوات المركزية السريعة دون الحاجة لمغادرة الشاشة الحالية:
1. **شريط نبض المنظومة (System Health Radar):**
   - مؤشر جهوزية السحابة: `🟢 السحابة المركزية متصلة · 99.9%`.
   - عداد الولايات النشطة: `58 ولاية مغطاة`.
2. **أزرار الإجراءات السريعة (One-Click Actions):**
   - 🚨 **بث وطني عاجل:** يفتح `NationalBroadcastModal` لبث إشعار فوري لجميع الأكشاك في كل الولايات.
   - ⚡ **خدمة جديدة:** يفتح استوديو التوليد الرقمي فوراً بمقاس A4.
   - 🧾 **فاتورة جديدة:** يفتح `CreateInvoiceModal` لإنشاء فاتورة B2B فورية لمحل أو موزع.
   - 💳 **توليد كروت شحن:** يفتح نموذج التوليد السريع لدفعات كروت الشحن للموزعين.
3. **زر تبديل المظهر (ThemeToggle):** تكامل تام مع محرك الألوان الجديد ومفتاح الوضع المظلم/المشرق.
4. **جرس التنبيهات المباشرة (Live Notification Center):** عرض إشعارات النظام والتحذيرات اللحظية.

## 🎨 5. تصميم المكونات وفق نظام Shadcn UI الحديث

سيتم بناء وتنسيق جميع أجزاء اللوحة بالاعتماد التام على مكونات **Shadcn UI**:
- **البطاقات (Cards):** استخدام `Card`, `CardHeader`, `CardTitle`, `CardDescription`, `CardContent` مع تأثيرات زجاجية خفيفة (`bg-card/80 backdrop-blur border-border/60`).
- **الجداول (Data Tables):** جداول Shadcn كاملة مع رأس ثابت، ألوان متناسقة، ترقيم صفحات (Pagination)، وفرز الأعمدة.
- **الشارات (Badges):** استخدام مكون `Badge` لتوضيح حالات الولايات (نشطة جداً، متوسطة، هادئة)، وحالات المحلات (نشط، مجمد، في التجربة).
- **النوافذ المنبثقة (Dialogs / Modals):**
  - نافذة ملف المحل المتكامل (`ShopDetailsModal`).
  - نافذة البث الوطني العاجل (`NationalBroadcastModal`).
  - نافذة إنشاء الفاتورة وطباعتها (`CreateInvoiceModal` & `InvoicePrintModal`).
  - نافذة استوديو الوثيقة A4 (`StudioModal`).
- **حقول البحث والإدخال (Inputs):** حقول إدخال أنيقة متوافقة مع اختصار لوحة المفاتيح `/`.

## 🔄 6. خطة توجيه الحسابات وتسجيل الدخول (Auth & Routing Strategy)

```typescript
// في src/components/auth/LoginClientView.tsx
if (res.user?.role === "SUPER_ADMIN") {
  // توجيه مدير النظام مباشرة إلى اللوحة الموحدة الشاملة
  router.push("/admin"); // أو المسار الموحد المختار
} else {
  // توجيه أصحاب الأكشاك والموظفين إلى لوحة الكاونتر المعتادة
  router.push("/dashboard");
}
```

- توفير رابط انتقال سلس داخل اللوحة أو توحيد مسار العرض في `/admin` ليكون هو الحاوية الشاملة لمدير النظام مع استدعاء كافة أدوات الكاونتر فيه دون استثناء.
- توفير تزامن كامل عبر الـ URL Hash (مثلاً: `/admin#national-radar`، `/admin#counter-studio`، إلخ) لحفظ موقع المشرف عند التحديث.

## 🛠️ 7. مراحل التنفيذ التفصيلية (Step-by-Step Implementation Roadmap)

### 🔹 المرحلة 1: توحيد سياق التبويبات وتوسيع الـ Tab Context
- **الملف:** `src/contexts/DashboardTabContext.tsx` أو إنشاء سياق موحد `src/contexts/SuperAdminTabContext.tsx`.
- **الهدف:** دعم جميع تبويبات الـ 58 ولاية وتبويبات الكاونتر في معرّف حالة واحد منضبط بالأنواع (TypeScript Types).

### 🔹 المرحلة 2: بناء القائمة الجانبية السيادية الموحدة (Unified Master Sidebar)
- **الملف:** `src/components/admin/layout/AdminUnifiedSidebar.tsx`.
- **الهدف:** بناء قائمة جانبية تدعم الأقسام الثلاثة (القيادة المركزية، كاونتر الخدمات، إعدادات العتاد)، مع خيار الطي، وشارات الحالات، واختصارات لوحة المفاتيح.

### 🔹 المرحلة 3: دمج استوديو الخدمات وسجل الوثائق داخل العرض الموحد
- **الملف:** `src/components/admin/AdminClientView.tsx` وربطه مع:
  - `ServicesFullGrid` و `StudioModal` للتشغيل الفوري للخدمات.
  - `DocumentsTab` لأرشيف الوثائق الوطنية والمحلية.
  - `WalletTab` لمحفظة الرصيد والشحن.
  - `SettingsTab` لإعدادات الطباعة.

### 🔹 المرحلة 4: ترقية الهيدر الوطني بأزرار الإجراءات السريعة وشريط نبض السحابة
- **الملف:** `src/components/admin/AdminHeader.tsx`.
- **الهدف:** إضافة أزرار الإطلاق السريع (خدمة جديدة، بث وطني، فاتورة جديدة، توليد كروت) متكاملة مع النوافذ المنبثقة.

### 🔹 المرحلة 5: مواءمة مكونات Shadcn UI والوضع المظلم/المشرق
- التحقق من جميع بطاقات الـ 58 ولاية، الجداول، المودالات، والأزرار بحيث تتطابق 100% مع متغيرات CSS في نظام التصميم الجديد وتعمل بسلاسة تامة في كلا الوضعين.

## 🚀 9. خطة الفحص والتحقق (QA & Verification Plan)
1. **فحص الدخول المباشر:** تسجيل الدخول بـ `admin@sahla.dz` والتأكد من فتح اللوحة الشاملة فوراً دون توجيهات متضاربة.
2. **فحص التنقل بين الأقسام:** التبديل بسلاسة بين رادار الـ 58 ولاية، واستوديو الخدمات A4، وسجل الفواتير دون أي فقدان لحالة الصفحة أو إعادة تحميل.
3. **فحص استوديو الوثيقة:** فتح خدمة (مثل: السيرة الذاتية أو صور بيومترية) من داخل اللوحة الموحدة، وتوليد وثيقة والتأكد من إضافتها لسجل الوثائق وتحديث رصيد المدير.
4. **فحص البث الوطني والفواتير:** اختبار فتح نافذة البث العاجل ونافذة الفاتورة وطباعتها والتأكد من دعم الخطوط العربية والشعار.
5. **فحص تبديل الثيم:** التبديل بين الوضع المظلم والمشرق والتأكد من وضوح كل النصوص والبطاقات والجداول بنسبة 100%.
