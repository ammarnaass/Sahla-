## 🎯 1. أهداف الخطة ونطاق العمل (Scope & Objectives)

بناءً على طلبكم الكريم، تهدف هذه الخطة إلى ترقية تجربة تسجيل الدخول وتطهيرها من بيانات الاختبار القديمة، مع توفير وصول مباشر وسلس للإدارة العليا وتمكين الزوار من استكشاف المنصة بحرية:

1. **حذف الحسابات التجريبية الجاهزة للاختبار (Clean-up):**
   * إزالة بطاقات الحسابات التجريبية بنقرة واحدة:
     - حساب صاحب الكشك: `najah.kiosk@gmail.com`
     - حساب مدير النظام: `admin@sahla.dz`
   * إلغاء الشريط القديم `DemoCredentialsBar` من صفحة تسجيل الدخول (`LoginClientView.tsx`) ومن النافذة المنبثقة `AuthModal.tsx`.
2. **إضافة زر مخصص للوصول إلى لوحة تحكم مدير النظام (Super Admin Portal Button):**
   * زر بارز وأنيق بلون كهرماني ملكي (`amber-500`) يحمل أيقونة التاج `Crown` وشارة `SUPER ADMIN (58 ولاية)`.
   * يتيح لمدير النظام الانتقال المباشر أو تسجيل الدخول بصلاحيات الإدارة الشاملة نحو `/admin`.
3. **بناء مراقب حالة تسجيل الدخول الحي (Auth & Session State Monitor):**
   * مكون مرئي وتفاعلي (`AuthStateMonitor`) يعرض بدقة:
     - **الحالة الحالية:** (🟢 متصل كمسؤول / 🟢 متصل كصاحب كشك / ⚪ غير مسجل - وضع ضيف).
     - **بيانات الجلسة:** الاسم، الدور، الولاية، ونوع الصلاحية.
     - **إجراءات سريعة:** التبديل، التحديث اللحظي للجلسة، وتسجيل الخروج بنقرة واحدة.
4. **توفير خيار "التجول في الموقع" (Guest Platform Tour):**
   * زر وخيار مرئي واضح: `🧭 التجول في الموقع كزائر (معاينة كاونتر الخدمات)`.
   * ينقل المستخدم مباشرة للوحة التحكم ودليل الخدمات `/dashboard#services` لاستكشاف ميزات المنصة والذكاء الاصطناعي كضيف دون حواجز تسجيل.
